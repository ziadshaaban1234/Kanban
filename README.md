# 🗂️ Kanban Task Manager

**Kanban Task Manager** is a modern, responsive task management web application built to help users organize their workflow efficiently using the Kanban methodology.

The application provides a clean board-style interface where tasks can be created, tracked, and managed across different workflow stages such as **To Do**, **In Progress**, and **Done** — all inside a smooth and user-friendly dashboard experience.

Designed with a focus on **productivity, simplicity, and responsive UI clarity**, this project demonstrates real-world Angular component structure and modern frontend development practices.

## ✨ Core Features

- 📝 **Task Management System**  
  Create and manage tasks easily through an organized workflow experience.

- 📌 **Kanban Board Layout**  
  Tasks are structured visually inside a Kanban-style board for better tracking and productivity.

- ✅ **Task Progress Tracking**  
  Move tasks through different stages based on completion status.

- 🎯 **Clean & Responsive UI**  
  Built with Bootstrap for a modern interface that works smoothly across all screen sizes.

- 🔔 **User-Friendly Experience**  
  Simple interactions and organized layout designed for daily task planning.

## 🛠️ Technical Stack

- **Framework:** Angular (Standalone Components)
- **Language:** TypeScript
- **UI Styling:** Bootstrap 5
- **Icons:** Font Awesome
- **Architecture:** Modular Component-Based Structure
